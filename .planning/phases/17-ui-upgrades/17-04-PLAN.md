<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Human verification of all 6 UIUP requirements</name>
  <action>
  Present the verification checklist to the user. All 6 UIUP requirements implemented/verified:

  1. UIUP-01: Collapsible analysis panel above reply editor
  2. UIUP-02: Banned phrase inline highlights with mode toggle + copy-blocking
  3. UIUP-03: Live word count (pre-existing, verified)
  4. UIUP-04: Prompt badge + override dropdown (pre-existing, verified)
  5. UIUP-05: Variant A/B selector for Reply V2 and Follow-Up V2
  6. UIUP-06: Next-step warning bar (pre-existing, verified)
  </action>
  <how-to-verify>
  Start the dev server (`npm run dev` in project root, `npm run dev` in client/).

  **UIUP-01 — Analysis Panel:**
  1. Select an email and click Generate Reply
  2. After generation, look for a collapsed "AI Analysis" section above the textarea
  3. Click to expand — verify JOB ANALYSIS and/or LINK ANALYSIS blocks are shown
  4. Copy to clipboard — verify analysis text is NOT in the clipboard content

  **UIUP-02 — Banned Phrase Highlights:**
  1. Generate a reply that triggers banned phrase detection (use a prompt override if needed)
  2. If violations detected, verify red highlights appear inline in the textarea (Flag mode)
  3. Toggle mode using the "Mode:" toggle near the violation list
  4. In Flag mode: verify copy button is disabled while phrases remain; edit the text to remove the phrase; verify copy button enables
  5. In Auto-rewrite mode: verify no highlights (phrases already rewritten), copy works

  **UIUP-03 — Word Count (verify only):**
  1. After generation, verify "X / Y words" appears below the editor
  2. Verify color is green (under limit), yellow (near limit), red (over limit)

  **UIUP-04 — Prompt Badge (verify only):**
  1. After generation, verify "Using: [Prompt Name]" badge in the editor header
  2. Change the override dropdown to a different prompt
  3. Click Generate Reply — verify it uses the overridden prompt

  **UIUP-05 — Variant Selector:**
  1. Generate using Reply V2 or Follow-Up V2 prompt (if the stored template produces 2 variants)
  2. Verify two clickable variant panels appear (Variant A — Direct, Variant B — Value-First)
  3. Verify copy button is disabled until a variant is selected
  4. Click a variant — verify text populates the editor and copy enables
  5. Generate using Thread Continuation or Proposal — verify NO variant selector appears

  **UIUP-06 — Next-Step Warning (verify only):**
  1. After generation, check if a yellow warning bar appears for replies without a next step
  2. Edit the reply to add "Can we talk Thursday?" — verify the warning disappears
  3. Verify copy button is NOT blocked by the warning (soft warning only)
  </how-to-verify>
  <resume-signal>Type "approved" if all 6 features pass verification, or describe any issues found</resume-signal>
</task>

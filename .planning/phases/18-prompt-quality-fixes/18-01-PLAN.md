<task type="auto">
  <name>Task 1: Create promptEnhancements.js utility module</name>
  <files>src/utils/promptEnhancements.js</files>
  <action>
Create a new CommonJS module `src/utils/promptEnhancements.js` with three pure, synchronous, exported functions:

**1. `detectPricingLanguage(emailText)`**
- Takes the client's email body text (string)
- Returns `{ hasPricing: boolean, keywords: string[] }` where `keywords` lists the matched terms
- Match patterns (case-insensitive, word-boundary):
  - English: `cost`, `budget`, `pricing`, `price`, `rates`, `rate`, `how much`, `hourly`, `fixed price`, `quote`, `estimate`, `fee`, `fees`, `affordable`, `expensive`, `cheap`
  - Common non-English pricing terms per CTA-05 edge case: `kosten` (German), `prix` (French), `presupuesto` (Spanish), `prezzo` (Italian), `preco` (Portuguese)
- Returns `{ hasPricing: false, keywords: [] }` for null/undefined/empty input (never throws)
- NOTE: This is a detection function for the CLIENT'S email, not for the generated reply. It determines whether to inject cost context into the prompt, NOT whether to strip pricing from output.

**2. `appendSignatureBlock(replyText)`**
- Takes the clean reply text after Claude generates it (string)
- Strips any existing trailing "Best,\nAshish" or "Best, Ashish" sign-off (case-insensitive, flexible whitespace)
- Appends the full HipHype Tech signature block:
```
Best,
Ashish
Business Development Manager
HipHype Tech (MindCrew Technologies)
https://hiphype.tech
```
- Returns the modified text string
- If input is null/empty, returns empty string (never throws)
- The signature must appear after the reply body and before any internal analysis blocks (caller handles block ordering -- this function operates on clean text only)

**3. `formatTimezoneCTA(ianaTimezone)`**
- Takes an IANA timezone string (e.g., "Pacific/Auckland", "America/New_York") or null/undefined
- If timezone is valid: formats current date's tomorrow at 11 AM in that timezone using `Intl.DateTimeFormat` and returns a string like `"11:00 AM NZDT (your time)"` -- uses `timeZoneName: "short"` for the abbreviation
- If timezone is null/undefined/invalid: returns the fallback string `"11 AM your time"` (per CTA-01 edge case -- graceful degradation)
- Never throws -- wraps `Intl.DateTimeFormat` in try/catch, returns fallback on any error
- Does NOT call any external API -- this is a pure formatting function that takes an already-resolved IANA timezone

Module header should document Phase 18 requirements covered and that these are pure functions with no DB/API dependencies.

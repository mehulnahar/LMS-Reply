<task type="auto">
  <name>Task 2: validateReply.js — all 4 scanner functions</name>
  <files>src/utils/validateReply.js</files>
  <action>
    Create `src/utils/validateReply.js` as a pure CommonJS utility module (no DB calls, no async, no side effects).

    Implement these exported functions:

    **1. `proposalGate(text, promptType, clientRequestedPricing = false)`** — VALIDATE-01 + QUALITY-03
    - If `promptType === 'PROPOSAL_V4'` AND `clientRequestedPricing === true`: return `{ text, stripped: false }` unchanged
    - Otherwise: scan for pricing patterns and replace with `CALL_REDIRECT`
    - PRICING_PATTERNS (narrowed per research pitfall 3 — avoid over-aggressive matching):
      - `/\$[\d,]+(?:\.\d{2})?/g` — dollar amounts only (not bare $)
      - `/\bUSD\b/gi`
      - `/\bpric(?:e[sd]?|ing)\b/gi` — price/prices/priced/pricing
      - `/\bbudget(?:\s+(?:constraint|of|for|is|was))?\b/gi` — budget in context
      - `/\bphase\s+[1-9]\b/gi` — phase 1, phase 2 etc
      - `/\btimeline\s+(?:of|for|is|would|will)\b/gi` — timeline when followed by specifics
      - `/\bdeliverable[s]?\s+(?:include|are|will|would)\b/gi` — deliverables in list context
    - Replace each match with `CALL_REDIRECT = "I'd love to discuss the details on a quick call."`
    - Reset `lastIndex = 0` after each `/g` pattern test to avoid regex state pollution (pitfall 1)
    - Return `{ text: cleaned, stripped: boolean }`
    - For PROPOSAL_V4 without clientRequestedPricing: also scan the proof section for metrics using `metricsScanner`. If no metrics found, call `removeProofSection(text)` before running pricing scan.

    **2. `bannedPhraseScanner(text, bannedPhrases)`** — VALIDATE-02
    - `bannedPhrases` is an array of `{ phrase, category, replacement_suggestion, active }` objects
    - Filter out inactive phrases (`if (!bp.active) continue`)
    - Case-insensitive indexOf scan on `text.toLowerCase()`
    - Return array of violation objects: `{ phrase: bp.phrase, index: idx, category: bp.category, replacement: bp.replacement_suggestion || null }`
    - Auto-rewrite: if `bp.replacement_suggestion` exists, replace phrase in text. Return both `violations` array (for frontend display) and `rewrittenText` (phrase replaced)
    - Return `{ violations, rewrittenText }` — caller decides which to use

    **3. `nextStepScanner(text)`** — VALIDATE-04
    - Split text into sentences using `/(?<=[.!?])\s+/` (Node.js >= 10 lookbehind — safe per research)
    - Check last 2 sentences (or all if fewer)
    - Return `{ hasNextStep: true }` if:
      - Any sentence contains `?` (direct question), OR
      - Action verb pattern + timeframe pattern both match in the last-2 block:
        - Action: `/\b(let me know|reply|respond|confirm|schedule|book|send|share|reach out|get back|available|connect|discuss|talk|call)\b/i`
        - Timeframe: `/\b(today|tomorrow|monday|tuesday|wednesday|thursday|friday|this week|next week|within \d+|by end|eod|asap|soon)\b/i`
    - Return `{ hasNextStep: false, lastTwoSentences: string }` otherwise

    **4. `metricsScanner(text)`** — QUALITY-04
    - Scan for: percentages (`\d+%`), multipliers (`\d+x\b`), or quantity+timeframe (`\d+\s*(days?|weeks?|months?|hours?|clients?|projects?|years?)`)
    - Return `{ hasMetrics: boolean }`

    **5. `removeProofSection(text)`** — QUALITY-04 helper (not exported)
    - Look for a "proof" paragraph: text between empty lines that contains phrases like "we have", "our work", "we've", "similar clients", "previously", "delivered"
    - If found and `metricsScanner(paragraph).hasMetrics === false`: remove that paragraph block
    - Return the cleaned text (or original if no proof section found)

    Module-level constant:
    ```javascript
    const CALL_REDIRECT = "I'd love to discuss the details on a quick call.";
    ```

    Exports:
    ```javascript
    module.exports = { proposalGate, bannedPhraseScanner, nextStepScanner, metricsScanner, CALL_REDIRECT };
    ```

    Follow CommonJS `'use strict';` convention at top of file.
  </action>

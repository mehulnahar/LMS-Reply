  <action>
Create `src/utils/promptRouter.js` with a pure function `determinePromptType(email, job, options)`.

Decision tree (in strict priority order):
1. If `options.promptOverride` is provided AND is a valid enum value → return it (manual override, PROMPT-04)
2. If `options.source === 'proposal'` → return `'PROPOSAL_V4'`
3. If `options.source === 'mockup'` → return `'LOVABLE_MOCKUP_V1'`
4. If `email.is_ooo === true` OR `email.intent === 'ooo'` → return `null` (STOP — suppressed, no AI call)
5. If `job.thread_client_messages >= 2` OR `job.thread_depth >= 2` → return `'THREAD_CONTINUATION_V1'`
6. If days since `email.received_at` >= 3 AND `job.thread_depth >= 1` → return `'FOLLOW_UP_V2'`
7. Default → return `'EMAIL_REPLY_V2'`

The `null` return value for STOP suppression is the signal to the route handler to NOT call Claude and instead return a suppressed response.

Fallback for thread depth: if `job` is null or `thread_depth === 0`, check whether `thread_depth` can be derived (pass-through — the route handler will compute this if needed). The function should not query the DB; it works only with data passed in.

```javascript
'use strict';

const VALID_PROMPT_TYPES = [
  'EMAIL_REPLY_V2',
  'THREAD_CONTINUATION_V1',
  'FOLLOW_UP_V2',
  'PROPOSAL_V4',
  'LOVABLE_MOCKUP_V1',
];

const PROMPT_TYPE_LABELS = {
  'EMAIL_REPLY_V2':         'First Reply',
  'THREAD_CONTINUATION_V1': 'Thread Continuation',
  'FOLLOW_UP_V2':           'Follow-Up',
  'PROPOSAL_V4':            'Proposal',
  'LOVABLE_MOCKUP_V1':      'Lovable Mockup',
};

/**
 * Determines which prompt template to use for generation.
 * Returns a prompt_type_enum string, or null for STOP suppression.
 *
 * @param {Object} email  - email row from DB (received_at, intent, is_ooo)
 * @param {Object} job    - job row from DB (thread_depth, thread_client_messages)
 * @param {Object} options - { promptOverride?: string, source?: 'proposal'|'mockup'|null }
 * @returns {string|null}
 */
function determinePromptType(email = {}, job = {}, options = {}) {
  // 1. Manual override (PROMPT-04)
  if (options.promptOverride && VALID_PROMPT_TYPES.includes(options.promptOverride)) {
    return options.promptOverride;
  }

  // 2. Explicit button source
  if (options.source === 'proposal') return 'PROPOSAL_V4';
  if (options.source === 'mockup') return 'LOVABLE_MOCKUP_V1';

  // 3. STOP — suppress generation (OOO / stop intent)
  if (email.is_ooo === true || email.intent === 'ooo') return null;

  // 4. Ongoing thread (2+ client exchanges)
  const threadClientMsgs = (job && job.thread_client_messages) ? job.thread_client_messages : 0;
  const threadDepth = (job && job.thread_depth) ? job.thread_depth : 0;
  if (threadClientMsgs >= 2 || threadDepth >= 2) return 'THREAD_CONTINUATION_V1';

  // 5. Follow-up: client silent ≥3 days and thread has started
  if (email.received_at && threadDepth >= 1) {
    const daysSince = (Date.now() - new Date(email.received_at).getTime()) / (1000 * 60 * 60 * 24);
    if (daysSince >= 3) return 'FOLLOW_UP_V2';
  }

  // 6. Default: first reply
  return 'EMAIL_REPLY_V2';
}

module.exports = { determinePromptType, PROMPT_TYPE_LABELS, VALID_PROMPT_TYPES };
```

First install cheerio: `npm install cheerio` in the project root.

Create `src/utils/prefetch.js` with these exports:

**`ensureJobDescription(job, email, anthropicKey, leadhackCredentials)`**
- If `job.job_description_raw` is already populated, return immediately (cache hit)
- Otherwise, fetch from LeadHack: POST `https://app.leadhack.info:3000/api/admin/getJobDetails` with `{ email_id: email.from_email, email_subject: email.subject }`
- Requires LeadHack auth token first: POST `https://app.leadhack.info:3000/api/admin/getAuthToken` with credentials
- ALL fetches must use AbortController with 10000ms timeout
- On success: update `job.job_description_raw` in memory AND persist to DB via pool.query (pool required as parameter)
- On failure: throw an Error with message starting with 'LeadHack prefetch failed:' so the caller can catch and continue

The caller (replies.js) will pass the `pool` so prefetch.js should accept it as a parameter, not require it at module level.

**`extractUrls(...textSources)`**
- Accept variadic text strings (job_description_raw, email body_text)
- Regex: `/https?:\/\/[^\s"'<>)\]]+/g`
- Clean trailing punctuation: `.replace(/[.,;:!?)\]]+$/, '')`
- Deduplicate via Set
- Filter with domain blocklist: `['upwork.com', 'linkedin.com', 'twitter.com', 'x.com', 'facebook.com', 'googleapis.com', 'fbcdn.net', 'doubleclick.net', 'googletagmanager.com', 'gstatic.com', 'amazonaws.com']`
- Use `new URL(url).hostname.replace('www.', '')` for domain check
- Cap at first 5 valid URLs
- Skip URLs longer than 500 chars
- Return empty array (never null/undefined) when no valid URLs found

**`analyzeUrl(url)`**
- AbortController with 5000ms timeout — MANDATORY, never omit
- User-Agent header: `'Mozilla/5.0 (compatible; LMSReply/1.0)'`
- Accept header: `'text/html,application/xhtml+xml'`
- If HTTP error (non-2xx): record `error: 'HTTP {status}'`, return result with findings array containing `'Site returned {status} error'`
- If AbortError: record `error: 'Fetch timed out (5s limit)'`
- On success, use `const $ = cheerio.load(html)` and extract:
  - `title`: `$('title').text().trim()`
  - `description`: `$('meta[name="description"]').attr('content')`
  - `h1`: `$('h1').first().text().trim()`
  - Tech signals: scan `$('script[src]')` src attrs for 'react', 'vue', 'angular', 'jquery', 'shopify', 'wp-content'; also check `$('meta[name="generator"]').attr('content')` for 'WordPress', 'Shopify', 'Wix', 'Squarespace'
  - SEO gaps: missing meta description, no H1, images without alt (count with `$('img:not([alt])').length`), missing viewport meta
- `findings`: array of string observations (seo gaps + tech signals detected)
- `bestFindingForReply`: `findings[0]` or null
- Always return the result object — never throw (errors go in `result.error`)

**`analyzeAllUrls(urls)`**
- Run `analyzeUrl()` on each URL sequentially (not in parallel — avoid Railway timeouts)
- Return array of result objects
- If `urls` is empty, return `[]`

All functions must follow CommonJS: `module.exports = { ensureJobDescription, extractUrls, analyzeUrl, analyzeAllUrls }`.

Reference the existing LeadHack fetch pattern in `src/routes/jobs.js` for auth token + getJobDetails call shape.
